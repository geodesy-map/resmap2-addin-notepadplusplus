# resmap2-agent-notepadplusplus

## Installer le script python
1. Ouvrir __Notepad++__
2. `Plugins` > `Plugins Admin` > Installer _PythonScript_
3. `Plugins` > `PythonScript` > `New script` --> Nommez le "OpenInResMap2.py" et copier le contenu du fichier.
4. `Plugins` > `PythonScript` > `Configuration` --> Ajouter le script dans "Toolbar"
5. Redémarrer __Notepad++__

## Utilisation
1. Ouvrir le fichier `.prnx` dans __Notepad++__
2. Cliquer sur l'icône du script
